## SEUL Chat 1.0.0 — 첫 출시 🤖

귀여운 파란 로봇 **슬**과 평소에 대화하는 앱이에요. ChatGPT처럼 무엇이든 물어보세요.

### 할 수 있는 것
- **무료로 대화**: Google Gemini 무료 API 키(카드 필요 없음)만 넣으면 바로 사용. Claude API 키도 쓸 수 있어요.
- **성격 고르기**: 😊 친구 · 📚 선생님 · 🗣️ 영어 회화 · 🗂️ 똑똑한 비서
- **사진 넣기**: 버튼, 붙여넣기(Ctrl+V), 끌어다 놓기로 사진을 넣고 물어보기
- **대화 기록과 검색**: 지난 대화를 목록에서 다시 열고, 글자로 찾기
- **Code AI로 만들기**: 대화하다가 "이거 만들어 줘"가 나오면 버튼 하나로 Code AI에서 바로 만들기
- **다크 / 라이트 모드**
- Gemini가 바쁘면 알아서 Flash-Lite로 바꿔서 빨리 답해요.

### 설치
- **Windows**: `SEULChat-Setup-1.0.0.exe` (약 2.3MB). "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. (서명 비용이 없어 뜨는 안내예요)
- **macOS**: `SEULChat-1.0.0.dmg`. 처음 열 때 막히면 앱을 **오른쪽 클릭 → 열기**를 누르세요.

Code AI에 넣은 API 키를 같이 써요. Code AI를 쓰고 있었다면 키를 다시 넣지 않아도 돼요.
