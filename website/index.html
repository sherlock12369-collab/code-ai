AI와 함께 코딩하세요.

Code AI는 편집기 옆에서 결과물을 실시간으로 보여주는 AI 코딩 도구입니다. 말로 요청하고, 화면에서 바로 확인하고, 클릭 한 번으로 배포하세요.

Windows용 다운로드

버전 1.0.0 · Windows 10 이상 · 64비트

다른 플랫폼: Windows macOS VS Code 확장

두 가지 방식으로 사용하세요

같은 AI, 같은 기능. 익숙한 환경을 고르면 됩니다.

추천

데스크톱 앱

설치 후 바로 시작하는 독립 앱입니다. 편집기, AI 채팅, 실시간 미리보기가 한 화면에 들어 있어 처음 코딩하는 분께도 좋습니다.

  • Windows 10 이상 / macOS 12 이상
  • 템플릿에서 바로 시작
  • 원클릭 배포와 변경 기록 내장
Windows (.exe) macOS (.dmg)

VS Code 확장

이미 VS Code를 쓰고 있다면 확장으로 설치하세요. 사이드바에 AI 채팅이, 편집기 옆에 미리보기 패널이 열립니다.

  1. 마켓플레이스: 확장 탭에서 Code AI 검색 후 설치 (곧 공개)
  2. .vsix 파일: 아래에서 파일을 받은 뒤 명령 팔레트에서 Extensions: Install from VSIX… 실행
  3. 또는 터미널에서: 
    code --install-extension codeai-1.0.0.vsix
.vsix 다운로드 마켓플레이스 (준비 중)

결과물을 보면서 만드는 경험

Code AI 1.0에 들어 있는 기능입니다.

핵심 기능

실시간 미리보기

편집기 바로 옆에서 만들고 있는 결과물을 그대로 보여줍니다. 파일이 바뀌면 자동으로 새로고침됩니다.

  • HTML 사이트 → 실제 페이지 렌더링
  • Markdown 문서 → 렌더링된 문서
  • 이미지(PNG, JPG, SVG, GIF), PDF → 그대로 표시
→

미리보기 클릭 수정

미리보기에서 요소를 클릭하면 채팅에 첨부됩니다. "이거 빨간색으로"처럼 말하면 AI가 그 부분만 고칩니다.

원클릭 배포

버튼 하나로 프로젝트를 배포하고 공유 링크를 받으세요. 설정할 것이 없습니다.

변경 기록 / 되돌리기

AI가 파일을 고칠 때마다 스냅샷을 저장합니다. 목록에서 원하는 시점으로 언제든 복구하세요.

템플릿

쇼핑몰, 포트폴리오, 랜딩페이지, 보고서 문서 중에서 골라 빈 화면 없이 바로 시작하세요.

한국어 최적화

화면과 AI 지시문이 모두 한국어로 만들어졌습니다. 평소 말하듯 요청하면 됩니다.

자체 AI 모델

오픈소스 코드 모델을 자체 서버에서 실행합니다. Google, OpenAI 같은 외부 API를 사용하지 않습니다.

릴리스 노트

현재 버전: 1.0.0

  1. 1.1예정

    자동 업데이트로 배포 예정입니다. 데스크톱 앱을 실행하면 새 버전 알림이 표시되고, 바로 업데이트할 수 있습니다.

  2. 1.0.0최신
    • 실시간 미리보기 패널 (HTML, Markdown, 이미지, PDF)
    • 미리보기 클릭으로 요소 선택 후 수정 요청
    • 원클릭 배포와 공유 링크
    • 변경 기록과 이전 버전 복구
    • 템플릿: 쇼핑몰, 포트폴리오, 랜딩페이지, 보고서
    • 다크 / 라이트 테마

  3. 2.0이후

    오프라인 모드: 내 PC에서 모델을 직접 실행합니다.
